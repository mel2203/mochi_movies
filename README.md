# 🍡 Mochi Movies 🎬

A cute movie search website built with **React**. Find movies, browse results, and discover your next watch with Mochi! 🍿✨

## 📸 Screenshot

![Mochi Movies Screenshot](./mochi_movies_ss.png)

## ✨ Features

- 🔎 Search for movies
- 🎬 Browse movie results
- 📊 Display number of movies found
- 🍡 Kawaii Mochi-themed design
- 📱 Responsive UI

## 🛠️ Built With

- React
- JavaScript
- CSS
- Vite
- Movie API

## 🚀 Run Locally

```bash
npm install
npm run dev
```
